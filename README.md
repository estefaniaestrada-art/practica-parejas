# Proyecto: Aplicación de Login

## Estrategia de Ramas: Git Flow
En este proyecto implementamos **Git Flow** como estrategia de ramificación.

### Justificación de la elección:
1. **Control de calidad:** Mantiene la rama `main` limpia para producción mientras `develop` se utiliza para la integración continua.
2. **Aislamiento de funcionalidades:** Cada característica se trabaja en una rama `feature/*` independiente, reduciendo el riesgo de romper código en desarrollo.
3. **Control de versiones:** Facilita la creación de releases estables y su etiquetado formal (`v1.0.0`).
